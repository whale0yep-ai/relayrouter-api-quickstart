# 安全说明

## 密钥保护

- 不要提交真实 API Key；`.env` 仅用于本地开发，并应保留在忽略列表中。
- 不要把密钥放入网页前端、公开截图、文章、Issue 或聊天记录。
- 分享错误前移除 Authorization 头、密码、验证码、支付信息及私人请求内容。
- 环境变量设置命令也可能留在终端历史中，请按使用环境的安全规范管理凭证。

## 密钥泄露后

1. 立即撤销泄露密钥，创建新密钥。
2. 检查控制台请求、用量与余额，必要时联系平台支持。
3. 从文件、日志和截图中移除凭证，检查 Git 历史；删除最新文件内容不等于清除了历史记录。

## 报告问题

不要在公开 Issue 中提供凭证或可直接利用的敏感细节。账号和平台安全问题通过 [RelayRouter 支持入口](https://api.relayrouter.ai/customersupport) 联系平台。示例和文档的一般问题可以提交脱敏的 GitHub Issue。
