# Security

## API keys

Never commit real API keys to this repository.

Use environment variables for local development.

If a key is exposed:

1. Revoke it immediately.
2. Create a new key.
3. Remove it from local files and logs.
4. Check Git history before making the repository public.

## Reporting a security issue

Do not publish private credentials in a public issue.

Contact RelayRouter support:

https://api.relayrouter.ai/customersupport
