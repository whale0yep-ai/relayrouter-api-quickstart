# FAQ

## Where do I register?

Register here:

https://api.relayrouter.ai/register?aff=SukO

## Where do I create an API key?

Sign in to the RelayRouter console and open the API key or token management page.

## Where can I find model names?

Use the current model list or model pricing page:

https://api.relayrouter.ai/pricing

## Can I publish my API key?

No. Never publish an API key in source code, GitHub, screenshots, articles, or chat messages.

## Why does the model name fail?

Model availability may change. Copy the current model name from the RelayRouter model list.

## How can I check usage?

Use the RelayRouter console to review usage records, balance, and request logs.

## Where can I get support?

https://api.relayrouter.ai/customersupport
